## 🚀 Quick Start Guide for Testers

1. **Activate Plugin**
   - Go to WordPress Dashboard → Plugins
   - Find "Elementor GSAP Widgets Factory"
   - Click "Activate"

2. **Open Elementor Editor**
   - Edit any page with Elementor
   - Or create a new page

3. **Find GSAP Widgets**
   - Look in left sidebar widget panel
   - Search for categories:
     - `GSAP Text Animations`
     - `GSAP Image Animations`
     - `GSAP Backgrounds`
     - `GSAP UI Elements`

4. **Add Widget to Page**
   - Drag widget from panel to page
   - Drop it in desired section/column

5. **Configure Widget**
   - Click on widget to select it
   - Edit settings in left panel
   - Customize animation controls

6. **Preview Animation**
   - Click "Preview" button (eye icon)
   - Scroll to see animations trigger
   - Return to editor to adjust

7. **Publish & Test**
   - Click "Publish" or "Update"
   - View live page
   - Test on different devices/browsers

## 🐛 Common Issues & Solutions

### Widget Not Appearing
**Problem:** Can't find widget in Elementor panel
- ✅ Check Elementor is activated
- ✅ Check plugin is activated
- ✅ Clear Elementor cache: Elementor → Tools → Regenerate CSS & Data
- ✅ Refresh browser page (Ctrl+F5 / Cmd+Shift+R)

### Animation Not Working
**Problem:** Widget displays but doesn't animate
- ✅ Check browser console for JavaScript errors
- ✅ Verify GSAP scripts loaded (Network tab)
- ✅ Enable ScrollTrigger in widget settings
- ✅ Test on published page (not just editor)
- ✅ Scroll down to trigger animation
- ✅ Enable "Markers" to see trigger points

### Performance Issues
**Problem:** Page slow or animations laggy
- ✅ Limit to 5-10 animated widgets per page
- ✅ Reduce animation complexity/duration
- ✅ Disable animations on mobile if needed
- ✅ Check for conflicting plugins
- ✅ Test with default WordPress theme

### CSS Styling Issues
**Problem:** Widget looks broken or unstyled
- ✅ Clear all caches (plugin, browser, CDN)
- ✅ Regenerate Elementor CSS files
- ✅ Check for theme CSS conflicts
- ✅ Verify widget CSS files loaded

### ScrollTrigger Not Firing
**Problem:** Animation never triggers on scroll
- ✅ Check trigger start/end values (e.g., "top 80%")
- ✅ Enable markers to visualize trigger zone
- ✅ Ensure element is within viewport at some point
- ✅ Check for fixed positioning issues
- ✅ Verify ScrollTrigger library loaded
